# 留言接口约定

前端入口：`src/components/MessageBoard.vue`。网络适配层：`src/messages/api.mjs`。

复制 `.env.example` 为 `.env.local`，设置 `VUE_APP_MESSAGE_API_BASE_URL` 并重启开发服务。例如设为 `https://api.example.com/api`，前端访问 `/api/messages`。同源反向代理可设置为 `/api`。该配置是公开地址，不能放数据库密码或其他密钥。跨域部署由后端允许前端站点的 Origin 以及 GET、POST 和 Content-Type 请求头。

未配置地址时，页面使用演示留言，新增留言只保留在当前页面内存中；界面显示预览模式和提交结果，不会声称已保存到数据库。配置地址后不再使用演示数据或自动回退，接口失败会展示重试入口或保留输入供重试。

## 读取留言

`GET {API_BASE}/messages`

返回 `200 application/json`：

```json
{
  "messages": [
    { "id": "msg_001", "content": "你好呀，来留个脚印。", "createdAt": "2026-11-17T09:00:00Z" }
  ]
}
```

`id` 为唯一字符串或数字；`content` 为 1～120 个字符；`createdAt` 为可选 ISO 8601 时间。无留言返回空数组。前端对列表洗牌，每轮取完后再次洗牌，轮次边界避免连续重复；五条独立轨道由 CSS 动画驱动，不读取滚轮或开场动画进度。

## 提交留言

`POST {API_BASE}/messages`，请求头 `Content-Type: application/json`。

```json
{ "content": "你好呀，来留个脚印。" }
```

后端验证内容并成功写入数据库后，返回 `201 application/json`：

```json
{
  "message": {
    "id": "msg_002",
    "content": "你好呀，来留个脚印。",
    "createdAt": "2026-11-17T09:01:00Z"
  }
}
```

按回车或点击发送按钮提交留言。前端收到成功响应后清空输入，将后端返回的留言加入弹幕轮播，并从右侧展示一次。失败时保留输入。发送期间禁止重复提交，请求超时为 10 秒，前端不自动重发 POST。

建议错误状态：`400/422` 内容无效，`429` 发送频繁，`500` 保存失败。前端对 429 显示频率提示，其他错误显示加载或保存失败。当前未约定登录、审核、分页或删除接口；需要时在适配层扩展。后端仍需校验长度、内容并控制发送频率；页面按普通文本渲染留言。

## 交互

- 鼠标悬停左下角「留言」可展开单行输入框。桌面输入框位于入口右侧，窄屏位于按钮上方。移出后，未固定且未获得焦点的输入框会收起。
- 点击入口或用键盘激活可固定展开并聚焦输入。再次点击入口、点击外部或按 Escape 可收起并保留草稿。草稿非空时，表单内的「清空」按钮会清空输入并收起。发送成功也会清空输入。
- 留言框内滚轮及触摸事件不推进背景开场；弹幕由独立 CSS 时间轴推进。
- 离开首页时暂停弹幕，返回后继续；系统减少动态效果模式显示静态留言。
